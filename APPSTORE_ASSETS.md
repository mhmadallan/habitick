# App Store Assets & Metadata Guide

This guide covers preparing all text, images, and metadata required for iOS App Store and Google Play Store.

## Quick Overview

| Asset | iOS App Store | Google Play |
|-------|---|---|
| App Name | 30 characters | 50 characters |
| Subtitle | 30 characters (iOS only) | — |
| Description | 4000 characters | 4000 characters |
| Short Description | — | 80 characters |
| Keywords | 100 characters | — |
| Screenshots | 2-5 (required) | 2-8 (required) |
| Feature Graphic | — | Required (1024x500) |
| Icon/Logo | 1024x1024 | 512x512 |
| Video Preview | Optional | Optional |
| Privacy Policy | Required | Required |
| Support URL | Required | Optional |
| Marketing URL | Optional | Optional |
| Category | Required | Required |
| Content Rating | Required | Required |
| Age Rating | Required | — |

# iOS APP STORE

## 1. App Name (30 chars max)

Keep it short, memorable, and searchable.

```
Habitick
```

⚠️ **Note:** Can't change after submission. Choose carefully!

## 2. Subtitle (30 chars max) - iOS Only

Appears below app name in App Store.

```
Daily Habit Tracker
```

**Options to consider:**
- "Master Your Daily Habits"
- "AI-Powered Habit Tracking"
- "Build Better Habits Today"

## 3. Description (4000 chars max)

Appears in App Store detail page. Make it compelling!

```
Habitick helps you build better habits and track daily progress with AI-powered insights.

FEATURES:
• Track habits and tasks with custom frequencies
• Get AI-generated encouragement based on your progress
• Set point values for each task to gamify your routine
• View detailed progress analytics over time
• Organize tasks by category
• Track study items (books, language learning, etc.)
• Support for dark mode

HOW IT WORKS:
1. Create tasks with your desired frequency (daily, weekly, monthly)
2. Log your progress whenever you complete a task
3. Get personalized encouragement from our AI assistant
4. Watch your progress grow and adjust habits as needed

PRIVACY FIRST:
• Your data is encrypted and stored securely
• We never sell your information
• Sign in with Google for privacy-friendly authentication
• You own all your data and can export it anytime

PERFECT FOR:
• Building morning routines
• Learning new languages
• Reading goals
• Fitness tracking
• Productivity improvement
• Personal development

Start building better habits today!
```

**Tips:**
- Lead with main benefit
- List 5-8 key features
- Include use cases
- Mention unique selling points
- Be honest about limitations
- Keep paragraphs short
- Use bullet points
- No promotional language

## 4. Keywords (100 chars max)

Comma-separated keywords for search optimization.

```
habit tracker, daily habits, productivity, goal setting, habit building, task manager
```

**Best keywords for Habitick:**
- habit tracker
- daily habits  
- habit building
- task manager
- productivity
- goal setting
- routine
- self-improvement
- habit formation

## 5. Support URL

Public page where users can get help.

```
https://github.com/mhmadallan/habitick
```

**Better options:**
- Create a simple website/help page
- Use GitHub issues page  
- Use product documentation

## 6. Marketing URL (Optional)

Link to your app's marketing/landing page.

```
https://mhmadallan.github.io/habitick
```

## 7. Screenshots (2-5 required)

Image requirements:
- **Size:** 1170 x 2532px (iPhone 14 Pro)
- **Format:** PNG or JPEG
- **Content:** Show 2-5 key features
- **Text:** Include captions/callouts

**Recommended screenshots:**
1. **Home Screen / Task List** - First impression
   - Callout: "Organize & track your daily tasks"
   
2. **Progress View** - Analytics
   - Callout: "Monitor your habit progress"
   
3. **Add Task Screen** - Task creation
   - Callout: "Set custom frequencies & categories"
   
4. **Encouragement Screen** - AI feature
   - Callout: "Get AI-powered encouragement"
   
5. **Dark Mode** - Additional feature
   - Callout: "Dark mode for night time tracking"

**Design Tips:**
- Use clean, simple mockups
- Add app UI overlays showing actual features
- Use 2-3 colors from your brand
- Add 1-2 line text captions
- Show actual app content/data
- Make text readable at small sizes

**Tools to create screenshots:**
- [AppMockUp](https://www.appmockup.com/)
- Figma with iPhone template
- Screenshot directly from device + design app
- [Previewed.app](https://previewed.app/)

## 8. Preview Video (Optional)

15-30 second walkthrough video.

**Tools:**
- QuickTime (Mac) to record simulator
- Screen recording from device
- iMovie or Adobe Premiere to edit
- YouTube or Vimeo to host

50 chars - Alternative name if needed.

```
Habitick - Habit Tracker
```

## 5. Keywords (Comma-separated, no character limit)

```
habit tracker, daily habits, task manager, productivity, goal setting, habit formation, routine tracker, motivation, self-improvement, personal development, meditation, fitness tracking, learning tracker, reading log
```

## 6. Category

Select best fit:

- **Productivity** ← Best for Habitick
- Health & Fitness (if emphasizing health habits)
- Lifestyle
- Personal Development

## 7. Content Rating Questionnaire

Google will ask you to rate content:

**Typical answers for a habit tracker:**
- Violence: None
- Sexual content: None
- Obscene language: None
- Alcohol/tobacco/drugs: None (unless tracking substance use)
- Gambling: None
- Hate speech: None
- Personally identifiable information: Yes (email for auth)

## 8. Screenshots (2-8 recommended)

Same as iOS, but **Android-optimized dimensions:**

- **Size:** 1080 x 1920px (standard Android)
- **Format:** PNG or JPEG
- **Count:** 2-8 screenshots (use 3-5)

**Same content as iOS screenshot set:**
1. Home/tasks screen
2. Progress analytics
3. Add/edit task
4. AI encouragement
5. Dark mode (optional)

## 9. Feature Graphic (Required)

Large promotional image that appears at top of store listing.

- **Size:** 1024 x 500px
- **Format:** PNG or JPEG
- **Content:** Eye-catching, shows app brand/logo
- **Don't include:** Google Play logo, other brand logos

**Design ideas:**
- Large "Habitick" logo with app screenshot
- Motivational quote about habit building
- Habits --> Progress --> Success visual flow
- Your app color scheme with icon

## VERSIONS & UPDATES

### Version Number Format

For Capacitor/Ionic apps:

- **Format:** MAJOR.MINOR.PATCH (e.g., 1.0.0)
- **iOS:** Must match in Xcode project settings
- **Android:** Must correspond to versionCode in build.gradle

**Example versioning:**
```
1.0.0 - Initial release
1.0.1 - Bug fixes
1.1.0 - New feature (encouragement AI)
2.0.0 - Major redesign/breaking changes
```

### Build Numbers

**iOS:**
```
Xcode > App > Build Settings > Marketing Version: 1.0.0
```

**Android (build.gradle):**
```gradle
android {
    defaultConfig {
        versionCode 1    // Integer: 1, 2, 3, increment for each build
        versionName "1.0.0" // String: semantic versioning
    }
}
```

### Release Notes

Prepare for each release:

```
VERSION 1.0.0

NEW FEATURES:
• AI-powered encouragement for habit tracking
• Dark mode support
• Study items tracking (books, language learning)

IMPROVEMENTS:
• Better progress visualization
• Faster app launch
• Improved authentication stability

BUG FIXES:
• Fixed notification timing issues
• Resolved sync problems on offline apps
• Fixed dark mode theme inconsistencies

KNOWN ISSUES:
• None currently reported
```

## Checklist Before Submission

### Content Checklist

- [ ] Compelling, benefit-focused
- [ ] No placeholder text

- [ ] Icon 1024x1024px, high quality

- [ ] Screenshots 2-8 for Android (1080x1920)

- 100 chars ≈ 12-15 words (keywords)
